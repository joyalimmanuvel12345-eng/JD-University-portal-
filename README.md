JD University Advanced Examination Portal

A modern online university portal with premium Navy Blue and Gold branding.

Main Features

- Student Login and Registration
- Teacher and Administrator Login
- Online Examinations
- Results with Administrator Approval
- Student Attendance
- Fees Management
- Digital Student ID Cards
- University Announcements
- Student Reports

Technology

- Frontend: HTML, CSS and JavaScript
- Backend: Node.js and Express
- Database: PostgreSQL
- Hosting: Render

Project Status

Development in progress.
